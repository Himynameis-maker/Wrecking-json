## 3. RAM変数マップ [確定]

### 3.1 Mario（+$00）／ Spike（+$20）共通移動スロット（+$00〜+$17）
- $0300 / $0320: 状態（0=待機, 1=歩き, 2=はしご, 3=境界, 4=ハンマー, 5=ギミック, 6=連続はしご境界, 10=被弾）
- $0308 / $0328: 入力ビット（1=右, 2=左, 4=下, 8=上）。SpikeはAIが書く仮想入力
- $0309 / $0329: X座標（8bitラップ 0..255）
- $030D / $032D: はしご位置カウンタ P_rom（0..31、待機/歩きは0、判定閾値0/32）
- $030E / $032E: 上下進入可否（0=なし, 1=下可, 2=上可, 3=上下可。吸い付き範囲外は0）[sim.py未実装]
- $030F / $032F: 行（上位4bit）／列（下位4bit）。移動前位置から生成（((((Y-32)&$FF)>>1)&$F0) | (((X+8)&$FF)>>4)）
- $0310 / $0330: 行レジスタ（$030F & #$F0 / $032F & #$F0）
- $0312 / $0332: 現在向き（縦4/8, 横1/2, 0→1開始は $0308&3, 停止時+1）
- $0313 / $0333: はしご上端基準Y（enter: Y-32, enter_top: Y）
- $0315 / $0335: Y座標

### 3.2 Spike AI専用変数（+$19, +$1A）
- $0339: Spikeが記憶しているMarioの向き（書込元 $D229 のみ）
- $033A: AI持続タイマー（書込元 $D1C9 減算, $D1E6=$20, $D1F3=0 のみ）

## 4. 確定仕様：フレーム進行・移動エンジン・AI

### 4.1 1フレームの処理順 [確定]
1. 毎F先頭でマリオ入力 $0308 反映（実コントローラ入力の1F遅れ。Left+Right同時押しは $0308=0 に打ち消し）。
2. マリオ移動処理（Slot 0）。
3. 奇数フレームのみ（$0320 != $FF, $0317 & 8 == 0, $27 & 1）親方AI実行（$D164）。
   ※親方の $032F は親方移動先頭で作られるため、AI時点では1F遅れ値（見た目上2F遅れ）を参照する。
4. 親方移動処理（Slot $20）。

### 4.2 親方AI（$D112〜$D289, $CC34〜$CC4F, $CCAD〜$CCC3）[確定]
1. 行・Y一致チェック（$D16E〜$D188）: 1F遅れ行レジスタ（$030F&$F0 vs $032F&$F0）を比較し、同値なら現在Yを比較。
2. 【行レジスタとYが一致時】（$D1C9〜$D22E）:
   - $033A -= 1。負（0→$FF）になったら期限切れとして $033A=$20 にセット。
   - $0312 == $0339 なら $033A=0 にし、$0328 = 水平ビット（$030F vs $032F を8bit比較し < なら左2, > なら右1, 同じなら0）で上書き。
   - $0312 != $0339（期限切れチックの $0312 ≠ 直前AIチックの $0339）なら $0328 は触らず $033A=$20 のまま延長。
   - 最後に $D229 で $0339=$0312 を保存し、出口壁判定（$D22F）へ進む。
3. 【行またはYが不一致時】（$D189〜$D1C6）:
   - 垂直ビット: 行レジスタが違えば行比較（親方>マリオで上8 / 小で下4）、同行なら現在Y比較。
   - 水平ビット（$CC34〜$CC4F）: 垂直が上(8)なら親方行、下(4)なら親方行+1 を対象に、$0500==1（上りはしご）を列0→15へ走査し親方列に最も近い1本を選ぶ（< のみ更新＝同距離は左優先）。見つかった位置 best_pos（無ければ0）と sp_pos（探索行*16 + 親方列）を8bit比較し、best_pos < sp_pos で左(2)、> で右(1)、同じなら $0332 & #$03（例: 行0×列0×はしご無しでは $0332&3、行1以上×列0では 0 < $10 で左）。
   - $0328 = 垂直 | 水平 とし、出口壁判定（$D22F）へ進む。
4. AI出口の壁8反転（$D22F〜$D289, $CCAD〜$CCC3）:
   - $0328 & 3 == 0 なら何もしない（左右同時3は右走査）。
   - 親方現在位置 $032F から進行方向へ「1マス進めて確認→列端判定」の do-while で $0500==8 を探す（右は列15の次の次行列0、左は列0の前の前行尻15まで1マスはみ出す）。
   - 壁8が見つかり、別行（$0310 != $0330）なら壁列と best_pos&$0F を比較（右: wall_col < target_col、左: wall_col >= target_col で通過）したうえで、同段・別行共通の CPY $030F 比較（右: wall_pos < ma.cr、左: wall_pos >= ma.cr）を通過したときのみ $0328 ^= #$03。

### 4.3 共通移動状態マシン（$BB78〜$CA14）[確定]
各ステップ先頭（$C7D6）で移動前位置から $030F/$032F を作成する。

- 吸い付き・はしご突入（$C6B8〜$C7C6）:
  - 待機(0)・歩き(1)のとき優先判定。((X+6)&$0F) < 12（タイル中心 -6〜+5px、列5なら 74〜85）かつ、上ビットなら現在タイル==1（ただし行0不可）、下ビットなら1行下==1（Y%32==0制限なし、非床Y=63でも下り進入可）で突入。
  - $0312/$0332 = bits & $0C、X = (X+8)&$F0。下り時は top_y=Y, P_rom=31, state=3(enter_top)。上り時は top_y=(Y-32)&$FF, P_rom=1, state=3(enter)。PLA; PLA で後続歩行処理をスキップ。
- 状態0（待機, $BB78）:
  - はしご突入しなければ水平入力（$0308 & 3）を確認（$C5C2）。ビットがあれば $0312/$0332 = $0308 & 3、Y = (Y+8)&$E0 後に壁8チェック（$C2AC）を通過すれば P_rom=0, state=1（壁なら状態0留まり。非はしごの縦入力では $0312 は変わらない）。
- 状態1（歩き, $BB9F）:
  - はしご突入しなければ壁8チェック（$C2AC）。壁なら状態0へ（dir+1）。
  - 継続条件 ($0308 & 3) == ($0312 & 3) を満たせば X += (-1 if dir&2 else +1) & $FF（左右同時3も左歩き）。外れれば動かず state=0, dir+1。
- 状態2（はしご, $BC17）:
  - Y=51〜63のみ $C316 で一時 $030F += $10 され直後 $C337 で戻る。
  - 縦入力($0308 & $0C)あり: $0312 = $0308 & $0C、P_rom += (+1 if 上 else -1)。32で上端到達（Y=top_y, P_rom=0, state=3 arrive_top）、0で下端着地（Y=(top_y+32)&$FF, P_rom=0, state=3 arrive）、1..31は Y = (top_y + rel_y(P_rom))&$FF（1..4:+31, 5..9:+27, 10..14:+23, 15..19:+19, 20..24:+15, 25..31:+11）。
  - 縦入力なし＆水平入力($0308 & 3)あり（$C5C2）: $0312 = $0308 & 3。P_rom < 10 なら Y=(Y+8)&$E0 後に壁8チェックを通過すれば P_rom=0, state=1。P_rom >= 10 は降りず留まる。
- 状態3（境界, $BDC3 + $C99F）:
  - 長さ: 下端登り(enter)・下端着地(arrive)は5F（6F目に遷移）。上端到達(arrive_top)は両者11F。上端下り(enter_top)はマリオ11F、親方8F。
  - 終了時は入力を見ず無条件遷移（$FF: enter/enter_top → state=2、$FD: arrive/arrive_top → state=0）。
- 壁8停止サブルーチン（$C2AC）:
  - X % 16 == 0 かつ進行方向隣（bits&1 非ゼロで cr+1、ゼロで cr-1）の $0500 == 8 なら停止（X%16!=0 時はすり抜け）。
